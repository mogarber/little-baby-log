# Little Baby Log — Architecture

Free, open-source (GPL-3.0) iPhone app for tracking a baby's sleep, feeding,
diapers, pumping, growth, and medicine. Think Huckleberry, minus the paywall.

**Principles:** no servers, no accounts, no analytics, no ads. Data lives on the
device and in the family's own iCloud. Caregivers share a baby via CloudKit
sharing. Designed for one-handed use at 3am: big targets, few taps, haptics.

## Repository layout

```
project.yml                     XcodeGen spec (source of truth; .xcodeproj is git-ignored)
Config/App.xcconfig             shared build settings (iCloud OFF by default)
Config/Local.xcconfig.example   copy to Local.xcconfig (git-ignored) to set team + enable iCloud
Config/LittleBabyLog.entitlements
Config/Info.plist               generated by XcodeGen from project.yml
App/                            iOS app target (SwiftUI, iOS 17+)
  LittleBabyLogApp.swift
  Support/                      AppDelegate/SceneDelegate, AppConfig, Prefs, env keys, sharing UI glue
  Views/                        SwiftUI screens
  Resources/Assets.xcassets
Packages/BabyLogKit/            Swift package: model, persistence, logic. Builds on macOS too,
                                so `swift test` runs without Xcode.
scripts/make-icon.swift         renders the 1024px app icon
```

Swift language mode 5 everywhere (package: tools 6.0 + `swiftLanguageModes: [.v5]`;
app: `SWIFT_VERSION = 5.0`). Deployment: iOS 17, macOS 14 (package only).

## Data model (Core Data, defined in code)

`BabyLogModel.model` builds the `NSManagedObjectModel` programmatically (no
.xcdatamodeld). CloudKit rules: every attribute optional or defaulted, no
unique constraints, all relationships optional with inverses. **Additive changes
only** once the CloudKit schema is deployed to production.

**Baby** (`@objc(Baby) public final class Baby: NSManagedObject`)
| attr | type |
|---|---|
| uuid | UUID? |
| name | String? |
| birthDate | Date? |
| createdAt | Date? |
| events | to-many LogEvent, cascade, inverse `baby` |

**LogEvent** (`@objc(LogEvent) public final class LogEvent: NSManagedObject`): one entity
for every kind, with kind-specific optional fields. One entity keeps sharing simple
(share the Baby and its whole graph goes along) and the timeline a single fetch.

| attr | type | used by |
|---|---|---|
| uuid | UUID? | all |
| kindRaw | String? | all (`EventKind.rawValue`) |
| startDate | Date? | all (instant kinds: the time) |
| endDate | Date? | sleep, breastfeed, pump. **nil on sleep/breastfeed = timer running** |
| notes | String? | all |
| createdAt, modifiedAt | Date? | all |
| leftSeconds, rightSeconds | Double = 0 | breastfeed: accumulated (paused) seconds per side |
| activeSideRaw | String? | breastfeed: side currently running, nil when paused |
| activeSideStartedAt | Date? | breastfeed: when active side started |
| lastSideRaw | String? | breastfeed: last side used (for "next side" hint) |
| amountML | Double = 0 | bottle |
| bottleContentRaw | String? | bottle |
| foodName | String? | solids |
| diaperKindRaw | String? | diaper |
| leftML, rightML | Double = 0 | pump |
| weightKg, lengthCm, headCm | Double = 0 | growth (0 = not measured) |
| medicineName, dose | String? | medicine (dose is free text, e.g. "2.5 ml") |
| baby | to-one Baby, nullify, inverse `events` |

All storage is metric. Display units are user prefs.

Running timers are stored in Core Data (not in memory), so they survive app kills
and **sync live to the other caregiver's phone**.

## BabyLogKit public API (the contract between the package and the app)

The app must only use what's listed here. The package must provide exactly this.

```swift
// Enums.swift
public enum EventKind: String, CaseIterable, Identifiable, Sendable {
    case sleep, breastfeed, bottle, solids, diaper, pump, growth, medicine
    public var id: String
    public var title: String        // "Sleep","Nursing","Bottle","Solids","Diaper","Pump","Growth","Medicine"
    public var symbolName: String   // moon.zzz.fill, heart.fill, waterbottle.fill, fork.knife, drop.fill, testtube.2, ruler.fill, pills.fill
    public var hasDuration: Bool    // sleep, breastfeed, pump
    public var isTimerBased: Bool   // sleep, breastfeed
    public var isFeed: Bool         // breastfeed, bottle
}
public enum BreastSide: String, CaseIterable, Identifiable, Sendable {
    case left, right
    public var id: String; public var title: String /* "Left" */; public var shortLabel: String /* "L" */
    public var other: BreastSide
}
public enum BottleContent: String, CaseIterable, Identifiable, Sendable { case formula, breastMilk, other; public var id: String; public var title: String /* "Formula","Breast milk","Other" */ }
public enum DiaperKind: String, CaseIterable, Identifiable, Sendable {
    case wet, dirty, mixed, dry
    public var id: String; public var title: String /* "Wet","Dirty","Wet + dirty","Dry" */
    public var isWet: Bool; public var isDirty: Bool
}

// BabyLogModel.swift
public enum BabyLogModel { public static let model: NSManagedObjectModel }

// Baby.swift
extension Baby {
    @nonobjc public class func fetchRequest() -> NSFetchRequest<Baby>
    public static func create(name: String, birthDate: Date, in context: NSManagedObjectContext) -> Baby  // sets uuid, createdAt
    public var displayName: String   // name, or "Baby" if empty
}

// LogEvent.swift
extension LogEvent {
    @nonobjc public class func fetchRequest() -> NSFetchRequest<LogEvent>
    /// Inserts into the SAME persistent store as `baby` (required for CloudKit shared store).
    public static func create(kind: EventKind, for baby: Baby, start: Date = .now, in context: NSManagedObjectContext) -> LogEvent
    public var kind: EventKind { get set }               // unknown raw → .sleep
    public var bottleContent: BottleContent? { get set }
    public var diaperKind: DiaperKind? { get set }
    public var activeSide: BreastSide? { get set }
    public var lastSide: BreastSide? { get set }
    public var isRunning: Bool                           // kind.isTimerBased && endDate == nil
    public func duration(at now: Date = .now) -> TimeInterval  // breastfeed: sum of sides; others: (end ?? now) - start; instant kinds: 0

    // Fetch requests (all sorted by startDate descending unless noted)
    public static func requestAll(baby: Baby, kinds: [EventKind]? = nil, ascending: Bool = false) -> NSFetchRequest<LogEvent>
    /// Events touching [date, ∞): startDate >= date OR endDate >= date OR running timer.
    public static func requestOverlapping(baby: Baby, from date: Date) -> NSFetchRequest<LogEvent>
    public static func requestRunning(baby: Baby) -> NSFetchRequest<LogEvent>
    /// fetchLimit 1. finishedOnly → endDate != nil.
    public static func requestLatest(baby: Baby, kinds: [EventKind], finishedOnly: Bool = false) -> NSFetchRequest<LogEvent>
}

// LogEvent+Nursing.swift — breastfeeding timer
extension LogEvent {
    public func breastSeconds(_ side: BreastSide, at now: Date = .now) -> TimeInterval
    public func totalBreastSeconds(at now: Date = .now) -> TimeInterval
    public func startSide(_ side: BreastSide, at now: Date = .now)   // pauses other side first; sets lastSide
    public func pauseNursing(at now: Date = .now)                    // banks elapsed into side; clears active side
    public func toggleSide(_ side: BreastSide, at now: Date = .now)  // active → pause, else start
    public func finishNursing(at now: Date = .now)                   // pause + endDate = now
}

// EventDraft.swift — value-type editing buffer so Cancel discards changes
public struct EventDraft: Equatable {
    public var kind: EventKind
    public var startDate: Date
    public var endDate: Date?            // sleep: nil = still asleep. breastfeed: nil = running timer (read-only in editor)
    public var notes: String
    public var leftSeconds: TimeInterval, rightSeconds: TimeInterval
    public var lastSide: BreastSide?
    public var pumpDuration: TimeInterval
    public var amountML: Double
    public var bottleContent: BottleContent
    public var foodName: String
    public var diaperKind: DiaperKind
    public var leftML: Double, rightML: Double
    public var weightKg: Double, lengthCm: Double, headCm: Double
    public var medicineName: String, dose: String

    /// New-entry defaults: sleep start now-1h/end now; breastfeed start now-15m, 0/0 sides,
    /// endDate = startDate (i.e. manual, not running); pump start now-15m, duration 15m; others start now.
    public init(kind: EventKind, now: Date = .now)
    public init(event: LogEvent)
    public var isRunning: Bool           // kind.isTimerBased && endDate == nil
    public var validationMessage: String? // nil when savable. Rules: start not > 1 min in future; sleep end > start and ≤ 24h;
                                          // manual breastfeed needs >0 total; bottle amount > 0; pump L+R > 0;
                                          // growth needs ≥1 measurement; medicine needs a name.
    /// Writes fields for this kind (sets endDate: breastfeed manual = start + L + R; pump = start + pumpDuration;
    /// instant kinds = nil). Running breastfeed: only start + notes are written. Sets modifiedAt. Trims notes (empty → nil).
    public func apply(to event: LogEvent, now: Date = .now)
}

// DaySummary.swift
public struct DaySummary: Equatable {
    public var sleep: TimeInterval        // overlap of sleeps with the interval (overnight sleep is split across days; running sleep counts up to now)
    public var feedCount: Int             // breastfeed + bottle starting in interval
    public var nursing: TimeInterval
    public var bottleML: Double
    public var solidsCount: Int
    public var diapers: [DiaperKind: Int]
    public var diaperCount: Int; public var wetCount: Int; public var dirtyCount: Int  // computed; mixed counts as both
    public var pumpML: Double
    public var medicineCount: Int
    public init()
    public init<S: Sequence>(events: S, interval: DateInterval, now: Date = .now) where S.Element == LogEvent
}

// Units.swift
public enum VolumeUnit: String, CaseIterable, Identifiable, Sendable {
    case milliliters, ounces
    public static let millilitersPerOunce: Double   // 29.5735295625
    public var id: String; public var symbol: String /* ml / oz */; public var title: String
    public func value(fromMilliliters ml: Double) -> Double   // rounded: ml to 1, oz to 0.1
    public func milliliters(from value: Double) -> Double
    public func format(milliliters ml: Double, locale: Locale = .current) -> String   // "120 ml", "4 oz", "4.5 oz"
}
public enum UnitSystem: String, CaseIterable, Identifiable, Sendable {
    case metric, imperial
    public var id: String; public var title: String; public var lengthSymbol: String /* cm / in */
    public static func poundsOunces(fromKilograms kg: Double) -> (pounds: Int, ounces: Double)  // oz rounded to 0.1
    public static func kilograms(pounds: Double, ounces: Double) -> Double
    public func lengthValue(fromCentimeters cm: Double) -> Double
    public func centimeters(fromLength value: Double) -> Double
    public func formatWeight(kilograms kg: Double, locale: Locale = .current) -> String  // "4.25 kg" / "9 lb 6 oz"
    public func formatLength(centimeters cm: Double, locale: Locale = .current) -> String // "55.5 cm" / "21.9 in"
}

// Formatting.swift
public enum DurationFormat {
    public static func short(_ interval: TimeInterval) -> String   // "1h 5m", "2h", "12m", "45s"
    public static func clock(_ interval: TimeInterval) -> String   // "5:09", "1:05:09"
}
public enum BabyAge {
    /// "Born today", "5 days old", "3 weeks, 2 days", "4 months, 1 week", "2 years, 3 months", "Due in 3 days"
    public static func description(birthDate: Date, now: Date = .now, calendar: Calendar = .current) -> String
}
public struct EventDescriber {
    public var volumeUnit: VolumeUnit; public var unitSystem: UnitSystem; public var locale: Locale
    public init(volumeUnit: VolumeUnit, unitSystem: UnitSystem, locale: Locale = .current)
    /// One-line detail for timeline rows, e.g. "1h 20m", "Asleep for 34m", "L 8m · R 6m", "120 ml formula",
    /// "Wet + dirty", "L 60 ml · R 50 ml", "4.25 kg · 55 cm · head 37 cm", "Tylenol · 2.5 ml"
    public func summary(for event: LogEvent, now: Date = .now) -> String
}

// CSVExporter.swift
public enum CSVExporter {
    public static let columns: [String]
    /// RFC 4180 quoting; ISO-8601 dates with offset; text fields starting with = + - @ get a leading ' (formula injection).
    public static func csv(for events: [LogEvent], timeZone: TimeZone = .current) -> String
}

// PersistenceController.swift
public enum SharingError: Error, LocalizedError { case cloudSyncDisabled, storeUnavailable }
public final class PersistenceController {
    /// cloudKitContainerIdentifier nil/empty → plain local NSPersistentContainer (builds without the iCloud entitlement;
    /// CKContainer throws an ObjC exception if the entitlement is missing, so never create one in that case).
    /// Otherwise NSPersistentCloudKitContainer with two stores: private.sqlite (.private scope) and shared.sqlite (.shared scope),
    /// both with history tracking + remote change notifications. Local mode uses the same private.sqlite filename so turning
    /// iCloud on later uploads existing data. inMemory uses /dev/null. Never fatalError: store load errors go to `loadError`.
    public init(cloudKitContainerIdentifier: String? = nil, inMemory: Bool = false, storeDirectory: URL? = nil)
    public let container: NSPersistentContainer
    public var viewContext: NSManagedObjectContext   // automaticallyMergesChangesFromParent, NSMergeByPropertyObjectTrumpMergePolicy
    public private(set) var privateStore: NSPersistentStore?
    public private(set) var sharedStore: NSPersistentStore?
    public private(set) var loadError: Error?
    public let cloudKitContainerIdentifier: String?
    public var cloudKitContainer: NSPersistentCloudKitContainer?
    public var isCloudSyncEnabled: Bool

    // Sharing (all no-ops / false / throw .cloudSyncDisabled in local mode)
    public func isInSharedStore(_ object: NSManagedObject) -> Bool   // true = shared WITH me (I'm a participant)
    public func existingShare(for object: NSManagedObject) -> CKShare?
    public func isShared(_ object: NSManagedObject) -> Bool
    public func canEdit(_ object: NSManagedObject) -> Bool            // canUpdateRecord(forManagedObjectWith:)
    /// Returns the existing share or creates one via container.share([baby], to: nil).
    public func share(_ baby: Baby) async throws -> (CKShare, CKContainer)
    public func acceptShareInvitations(from metadata: [CKShare.Metadata]) async throws  // into sharedStore
    public func persistUpdatedShare(_ share: CKShare)                  // into privateStore
    public func purgeSharedZone(of share: CKShare)                     // participant left: purge zone from sharedStore
}

// Context+Save.swift
extension NSManagedObjectContext {
    @discardableResult public func saveIfNeeded() -> Bool   // logs errors via os.Logger; never crashes, never rolls back
}

// SampleData.swift — for SwiftUI previews and tests
public enum SampleData {
    @discardableResult public static func populate(_ context: NSManagedObjectContext, now: Date = .now) -> Baby
    // Creates "Juniper", born 7 weeks ago, with ~3 days of realistic events + a growth entry; saves.
}
```

## App (iOS target)

**Config.** `Info.plist` key `LBLCloudKitContainer = $(CLOUDKIT_CONTAINER)`. `AppConfig.cloudKitContainerIdentifier`
reads it (nil if empty or unexpanded `$(`). `PersistenceController.shared` is built from it; `.preview` is in-memory
with `SampleData`. Exposed to views via `@Environment(\.persistence)` (default `.shared`) plus the standard
`\.managedObjectContext`.

**Prefs** (`@AppStorage`): `Prefs.selectedBabyID` (uuid string), `Prefs.volumeUnit` (`VolumeUnit`, default ounces if
`Locale.current.measurementSystem == .us` else ml), `Prefs.unitSystem` (`UnitSystem`, metric if locale metric else imperial).

**Share acceptance.** `AppDelegate` (via `@UIApplicationDelegateAdaptor`) returns a `UISceneConfiguration` whose
`delegateClass = SceneDelegate.self`. `SceneDelegate` handles `windowScene(_:userDidAcceptCloudKitShareWith:)` and
cold-launch `connectionOptions.cloudKitShareMetadata` → `PersistenceController.shared.acceptShareInvitations`.
Info.plist has `CKSharingSupported = YES`, `UIBackgroundModes = [remote-notification]`.

**Sharing UI.** `CloudSharingCoordinator` (`@MainActor`, `UICloudSharingControllerDelegate`): calls
`persistence.share(baby)` then presents `UICloudSharingController(share:container:)` from the top view controller
(not via a SwiftUI representable — that's buggy). `itemTitle` = baby name; `didSaveShare` → `persistUpdatedShare`;
`didStopSharing` → if participant (`isInSharedStore`) `purgeSharedZone`. Calls an `onChange` closure so rows refresh.

**Screens.**
- `RootView`: babies `@FetchRequest` sorted by createdAt; selected = matching `Prefs.selectedBabyID` or first.
  `loadError` → `ContentUnavailableView`. No babies → `OnboardingView`. Else `MainTabView(baby:)`.`id(baby.objectID)`.
- `MainTabView`: tabs Today / History / Trends / Settings. Holds `@State day = startOfDay(now)`, refreshed on
  `UIApplication.significantTimeChangeNotification` and scenePhase active; passes it to `TodayView(...).id(day)` so
  fetch predicates roll over at midnight.
- `TodayView(baby:day:)` — a `List`:
  1. **Active timers** (running sleep / nursing): `ActiveTimerRow` with live clock (`TimelineView` 1s), "Wake up"
     (sets endDate) or "Open" (nursing timer sheet).
  2. **Since last** (`SinceLastView`, 30s refresh): Awake-for / Asleep-for, last feed "2h 10m ago" + "Next: Right"
     (other side of latest finished nursing), last diaper. Section header shows `BabyAge`.
  3. **Quick actions** (`QuickActionsGrid`, 4-col grid of `KindIcon` buttons, `.buttonStyle(.borderless)`):
     Sleep toggles a sleep timer; Nursing creates a running breastfeed and opens `BreastTimerView`; others open
     `EventEditorView` for a new entry. Context menu on every tile: "Log past <kind>" (editor). Diaper context menu
     also has instant Wet / Dirty / Wet + dirty.
  4. **Today summary** (`DaySummaryView`): Sleep, Feeds (+ bottle total), Diapers (wet/dirty), Pumped.
  5. **Timeline**: today's finished events (`EventRow`), tap → editor (running nursing → timer), swipe to delete.
  Toolbar: `BabySwitcherMenu` (only when >1 baby; self-contained: own fetch + AppStorage). `.sensoryFeedback(.success)` on logs.
- `BreastTimerView(event:suggestedSide:)`: big total clock, two large Left/Right tiles each with its own clock and
  play/pause; tap = `toggleSide` + save (so partner sees it live). "Next" badge on suggested side before starting.
  Done = `finishNursing` (or delete if 0s). Discard (confirmation) = delete. On disappear: delete if never started.
- `EventEditorView(baby:target:)` with `enum EditorTarget: Identifiable { case new(EventKind), edit(LogEvent) }`.
  `Form` over an `EventDraft` (`@State`); Save disabled while `validationMessage != nil` (shown as footer).
  Per kind: sleep (start, "Still asleep" toggle, end, duration); nursing (start, L/R minutes, last side; running → start
  + notes only); bottle (amount in user unit, contents segmented); solids (food); diaper (segmented kind); pump (start,
  minutes, L/R amounts); growth (weight — imperial = lb + oz fields — length, head); medicine (name, dose). Notes for
  all. Edit mode adds Delete with confirmation. Numeric input uses a `NumberField` backed by a String `@State` parsed
  with the current locale (TextField(value:format:) only commits on return, and decimal pads have no return key).
- `HistoryView(baby:)`: all events grouped by day, newest first; section header = date + mini summary
  ("Sleep 13h 20m · 8 feeds · 7 diapers", overnight sleep counted using the previous day's events too); kind filter
  menu; "+" menu to log a past entry of any kind; tap to edit; swipe to delete.
- `TrendsView(baby:)`: 7 / 14 / 30 day segmented picker; Swift Charts cards: sleep hours per day, feeds per day,
  diapers per day stacked (Wet / Dirty / Both), bottle volume per day, weight over time (all growth entries). Each card
  shows the average over complete days (excluding today).
- `SettingsView`: Babies (edit / add via `BabyFormView`); Caregivers (`CaregiverRow` per baby: status "Not shared" /
  "Shared with N people" / "Shared with you by <owner>", Invite/Manage button → coordinator; if sync disabled, explain
  the build has iCloud off); Units pickers; "Export all data (CSV)" → temp file → `UIActivityViewController`; About
  (version, GPL-3.0 note, source link `AppConfig.sourceCodeURL`, "No accounts, no ads, no tracking").
- `BabyFormView(baby: Baby?, onSave:)`: name, birthday (date only; future allowed up to ~1 year = due date). Delete
  (with confirmation, cascades) only when not `isInSharedStore`.
- `OnboardingView(onCreate:)`: welcome, name + birthday, "Start tracking"; footnote about accepting a caregiver
  invite instead (the baby appears once iCloud syncs).
- `EventKind+Style.swift`: `color` (sleep indigo, breastfeed pink, bottle orange, solids green, diaper teal, pump
  purple, growth blue, medicine red) and `KindIcon(kind:size:)` (white SF Symbol on a gradient circle).

## Building

```
brew install xcodegen
xcodegen generate
open LittleBabyLog.xcodeproj
```
Runs in the simulator with iCloud off. To enable sync/sharing (paid Apple Developer account required):
copy `Config/Local.xcconfig.example` → `Config/Local.xcconfig`, set `DEVELOPMENT_TEAM` and `BUNDLE_ID_PREFIX`,
regenerate. Before App Store release, deploy the CloudKit schema to Production in the CloudKit Console.

Package tests: `cd Packages/BabyLogKit && ./test.sh`.
